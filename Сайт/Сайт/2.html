• Впервые Visual Studio Code был анонсирован компанией Microsoft 29 апреля 2015 года на конференции Build 2015. Вскоре после этого была выпущена предварительная версия. 18 ноября 2015 года проект «Visual Studio Code – Open Source» (также известный как «Code – OSS»), на котором основан Visual Studio Code, был выпущен под лицензией MIT с открытым исходным кодом и стал доступен на GitHub . Также была объявлена ​​поддержка расширений. 14 апреля 2016 года Visual Studio Code вышел из стадии публичного предварительного просмотра и был выпущен в веб-версию .
