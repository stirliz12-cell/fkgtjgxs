• Visual Studio Code включает редактор исходного кода, который можно использовать с различными языками программирования, включая C , C# , C++ , Fortran , Go , Java , JavaScript , Node.js , Python , Rust и Julia . Visual Studio Code использует тот же компонент редактора (под кодовым названием «Monaco»), что и в Azure DevOps (ранее называвшемся «Visual Studio Online» и «Visual Studio Team Services»). Загружаемая версия Visual Studio Code построена на основе фреймворка Electron , который используется для разработки веб-приложений Node.js , работающих на механизме компоновки Blink . Visual Studio Code for the Web — это браузерная версия редактора, которую можно использовать для редактирования как локальных файлов, так и удаленных репозиториев (на GitHub и Microsoft Azure ) без установки полной программы . Она официально поддерживается и размещается Microsoft и доступна по адресу vscode.dev . В стандартной комплектации Visual Studio Code включает базовую поддержку большинства распространенных языков программирования. Эта базовая поддержка включает подсветку синтаксиса , сопоставление скобок , сворачивание кода и настраиваемые фрагменты. Visual Studio Code также поставляется с IntelliSense для JavaScript, TypeScript, JSON , CSS и HTML , а также с поддержкой отладки для Node.js. Поддержка дополнительных языков может быть обеспечена с помощью бесплатных расширений, доступных на VS Code Marketplace.
